# LearnVista 🎓

**Cloud-Native Multi-Language Learning Management System (LMS)**
*🏆 1st Prize Winner - University Hackathon | 📜 Selected for Patent Filing*

---

### 📖 About
LearnVista is a scalable, cloud-hosted Moodle implementation designed to break language barriers in digital education. Unlike standard Moodle deployments, LearnVista features a custom-configured localization engine and optimized cloud architecture to handle concurrent user loads with low latency.

### ⚙️ Engineering Highlights
* **Localization Engine:** customized Moodle core modules to support dynamic multi-language content delivery, enabling seamless switching between regional languages.
* **Cloud Optimization:** Tuned server configurations (Nginx/Apache) and database queries to ensure high availability and secure access in a cloud environment.
* **Granular Security:** Implemented strict Role-Based Access Control (RBAC) to segregate data privileges between Administrators, Instructors, and Students.
* **Scalable Deployment:** Architected a deployment strategy focused on extensibility, allowing for easy integration of future plugins without breaking core functionality.

### 🛠️ Tech Stack
* **Core:** Moodle (Customized), PHP
* **Database:** MySQL / PostgreSQL
* **Infrastructure:** Cloud Hosting (AWS/Azure), Linux
* **Security:** RBAC, SSL/TLS Encryption

### 🚀 Achievements
* **Hackathon Winner:** Secured 1st Rank for best utility and scalability.
* **Patent Recognition:** System architecture was selected for patent filing due to its unique approach to localized content delivery.
